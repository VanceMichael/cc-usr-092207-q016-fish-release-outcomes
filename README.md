# 珍稀鱼类放流成效核验

核验珍稀鱼类从繁育放流到野外再发现和自然繁殖的成效。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括鱼类保育中心、放流执行单位、第三方生态监测人员、流域保护决策人员。

资料所依据的领域事实如下：

- 四川建有长江鲟保育中心并保存大量野生原种
- 金沙江上游多年累计放流珍稀特有鱼苗七百余万尾
- 监测中出现鱼类种类回升和长江鲟自然繁殖进展
- 放流尾数不等于种群恢复，成效以遗传批次存活、扩散范围和新发现个体来源归属判定
- 自然产卵信号须达到证据边界方可采信

## 核验链路

亲本血缘登记 → 繁育检疫 → 标记放流 → 运输容器与现场计数 → 河段水文 → 后续采样，各环节以批次号和容器号首尾衔接。混合样本或概率识别必须记录方法与置信度；标签脱落、重复捕获、计数纠正、异常死亡和监测方案换版只能追加分析修订，不得回改原始观察。繁育单位与第三方监测分别提交职责内证据，科研人员可复算存活与扩散指标，年度决策据此调整放流物种、数量和河段。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
